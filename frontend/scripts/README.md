# Frontend Scripts

Build and documentation scripts for the VirtualPyTest frontend.

## Build Pipeline

When `npm run build` is executed (either manually or via `frontend_prod.service`), npm's lifecycle hooks trigger the full pipeline:

```
npm run build
  │
  ├─ prebuild (automatic npm lifecycle hook)
  │   └─ scripts/prebuild.sh
  │       ├─ [1] API Docs Generation
  │       │     scripts/generate_api_docs.py (repo root)
  │       │     YAML specs → HTML via redoc-cli
  │       │     Input:  docs/api/specs/*.yaml
  │       │     Output: docs/api/docs/*.html
  │       │
  │       ├─ [2] MCP Docs Generation
  │       │     scripts/generate_mcp_docs.py (repo root)
  │       │     Tool definitions → markdown
  │       │     Input:  backend_server/src/mcp/tool_definitions/*_definitions.py
  │       │     Output: docs/mcp/mcp_tools_generated.md
  │       │
  │       ├─ [3] Security Reports Generation
  │       │     scripts/generate-security-docs.sh (repo root)
  │       │     Bandit + npm audit + Snyk → HTML report
  │       │     Output: docs/security/index.html + *.json
  │       │
  │       └─ [4] Copy Docs to Public
  │             scripts/copy-docs.sh (frontend dir)
  │             Copies generated docs + markdown → frontend/public/docs/
  │             Generates docs-manifest.json for navigation
  │
  └─ build
      vite build
      Bundles app + copies public/ → dist/
```

## Scripts

### prebuild.sh

Orchestrates the full documentation pipeline before Vite builds. Each step has graceful fallbacks:

| Step | Tool Required | Fallback |
|------|--------------|----------|
| API docs generation | `npx` + `redoc-cli` | Uses pre-existing HTML in `docs/api/docs/` |
| MCP docs generation | `python3` | Skips if MCP definition directory is missing |
| Security reports | `bandit`, `npm`, optionally `snyk` | Uses pre-existing report in `docs/security/` |
| Copy to public | `node` (for manifest generation) | Always runs, copies whatever exists |

### copy-docs.sh

Copies documentation from the repo `docs/` directory into `frontend/public/docs/` so Vite can serve them as static assets:

- OpenAPI HTML files → `public/docs/api/openapi/`
- Markdown docs (recursively following links) → `public/docs/<section>/`
- Security report HTML + JSON → `public/docs/security/`
- Generates `docs-manifest.json` for the frontend sidebar navigation

## Production Service

The systemd service (`config/services/linux/frontend_prod.service`) runs the full pipeline on every start/restart:

```
systemctl start vpt-frontend-prod
  → ExecStartPre: npm run build (triggers prebuild → build)
  → ExecStart: serve dist/ on :5073
```

Key service settings:
- `TimeoutStartSec=180` — allows time for doc generation + Vite build
- `PATH` includes `/home/vpt_user/.local/bin` for pip-installed tools (bandit)

## What Gets Served

| Frontend Route | Static Source | Generated By |
|---|---|---|
| `/docs/api` | `public/docs/api/openapi/*.html` | `generate_api_docs.py` → `copy-docs.sh` |
| `/docs/security` | `public/docs/security/index.html` | `generate-security-docs.sh` → `copy-docs.sh` |
| `/docs/*` | `public/docs/**/*.md` | `copy-docs.sh` (copied from `docs/`) |

## Adding New API Specs

1. Create YAML spec in `docs/api/specs/`
2. Run `npm run build` — prebuild will generate the HTML automatically
3. Update `frontend/src/pages/ApiDocumentation.tsx` to add the new spec to the dropdown

## Updating Security Reports

Security reports regenerate on every build if `bandit` is installed. To install the required tools:

```bash
pip install bandit safety   # Python security scanners
npm install -g snyk && snyk auth   # Optional: Snyk code analysis
```
