# VirtualPyTest Frontend Services

This directory contains system service configurations for running VirtualPyTest frontend components as background services.

## Linux Services (`linux/`)

### `vpt-frontend.service`
**Purpose**: Runs the VirtualPyTest React frontend development server
- **Executes**: `npm run dev` - Starts Vite development server
- **Environment**: NODE_ENV=development with color output enabled
- **Function**: Serves the React application with hot reload for development
- **Port**: 5173 (Vite default) or configured port
- **Restart**: Automatic restart on failure with 10-second delay

## Service Management

### Linux (systemd)
```bash
# Enable/start service
sudo systemctl enable vpt-frontend.service
sudo systemctl start vpt-frontend.service

# Check status
sudo systemctl status vpt-frontend.service

# View logs
sudo journalctl -u vpt-frontend.service -f

# Stop/disable service
sudo systemctl stop vpt-frontend.service
sudo systemctl disable vpt-frontend.service
```

## Notes
- This is a template file with `%USER%`, `%PROJECT_ROOT%` placeholders
- Actual service file is generated by setup scripts with correct paths
- Service runs under the specified user account
- Uses Vite for fast development with hot module replacement
- For production, the frontend is typically served by nginx or similar web server
