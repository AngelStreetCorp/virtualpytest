# VirtualPyTest Frontend

## 🎯 **Overview**

Frontend is the modern web interface that provides user access to the VirtualPyTest microservices ecosystem. It serves as the primary user-facing application for managing automated testing workflows, device control, and system monitoring.

## 🔧 **Software Stack**

- **Language**: TypeScript
- **Framework**: React 18
- **Build Tool**: Vite
- **UI Library**: Material-UI (MUI) v5
- **Runtime**: Node.js 18+

## 🏗️ **Core Libraries & Frameworks**

- **React Router**: Client-side routing and navigation
- **React Query**: Server state management and data fetching
- **Socket.IO Client**: Real-time WebSocket communication
- **TypeScript**: Type-safe JavaScript development

## 📋 **Application Services**

### **Core Features**
- **Dashboard**: System overview and quick action interface
- **Test Management**: Create, edit, and organize test cases
- **Campaign Management**: Organize and execute test campaigns
- **Navigation Editor**: Visual workflow and navigation tree design
- **Device Control**: Hardware interface and device management
- **Real-time Monitoring**: Live system status and metrics

### **Integration Services**
- **REST API Client**: HTTP communication with backend_server
- **WebSocket Service**: Real-time updates and live data streams
- **File Upload Service**: Direct file operations and asset management

## 🎯 **Main Purpose**

Frontend delivers a comprehensive web-based control center for VirtualPyTest, enabling users to design, execute, and monitor automated tests across physical devices. It provides an intuitive interface for managing the entire testing lifecycle while maintaining real-time visibility into system operations and device status.
