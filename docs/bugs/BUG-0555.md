# BUG-0555

## Symptom
iptv-org's fr.m3u ships 214 French channels, but "HTTP 200 + manifest" is NOT a playability test. A master playlist can answer 200 with a cached manifest while every variant 404s.

## Fix
Added docs/agent/iptv-france-streams/:
- STREAMS.md          doc with methodology + 137 working URLs grouped
- fr.m3u              clean playlist of the 137 entries (iptv-org #EXTINF / #EXTVLCOPT preserved)
- probe_iptv_fr.py    reproducible parallel probe (10s ffmpeg transcode)

## Verification
- $ python3 docs/agent/iptv-france-streams/probe_iptv_fr.py /tmp/iptv-fr/fr.m3u
- 137 ok . 71 fail . 6 timeout (out of 214)

## Numbers
The naive "200 + #EXTM3U" probe said 151 working. The real ffmpeg transcode says 137. The 14 over-count were BFM-family streams whose master playlists answered 200 from CDN cache but whose variant URLs 404.
