# QuickTest Builder

**A straight list of steps. No map of the app to build first.**

QuickTest Builder is the fastest way to make a test. Add steps one after another, run the test, and you are done.

---

## Why it exists

The full test builder, which works from a navigation map, is powerful. But it is not always what you need.

- Sometimes you only want to check "do this, then verify that".
- Mapping a whole app before a first check is too much work.
- New team members should be able to write a real test on their first day.

---

## What you get

- **A linear step list.** Add a step, pick an action or a check, then move to the next one.
- **Loops.** Repeat a group of steps a set number of times, without copying them.
- **The same engine and reports.** A QuickTest runs the same way as every other test, so its results look the same.
- **Nothing to set up first.** You do not need a navigation map. Describe what should happen, step by step.

---

## What it is good for

- A working test in minutes.
- Simple, repeatable checks. For example, going through a list of channels and checking that each one plays.
- New testers adding real tests straight away.
- Growing later. A QuickTest can become a full navigation-based test if you need one.

<div data-technical>

A QuickTest compiles to the same test-case engine as everything else, so it can grow into a full navigation-based test later.

</div>
