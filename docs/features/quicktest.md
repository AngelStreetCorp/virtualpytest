# 🧩 QuickTest Builder

**A straight list of steps. No navigation map to build first.**

QuickTest Builder is the fastest way to put together a test — add steps one after another, run it, done. No need to design a full navigation graph before you can start testing.

---

## The Problem

The full navigation-tree test builder is powerful, but it's not always what you need:
- ❌ Sometimes you just want to check "do this, then verify that" — nothing more
- ❌ Mapping out an entire app before writing your first test is overkill for a quick check
- ❌ New team members need a way to start testing on day one, without a learning curve

---

## The VirtualPyTest Solution

✅ **Linear step list** — add a step, pick an action or a verification, move to the next
✅ **Loops** — repeat a group of steps a set number of times, without duplicating them
✅ **Same engine, same reports** — runs through the exact same execution pipeline as every other test, so results look and behave identically
✅ **No prerequisites** — no navigation tree to build first; just describe what should happen, step by step

---

## How It Helps

- Get a working test running in minutes, not hours
- Perfect for straightforward, repeatable checks — for example, zapping through a list of channels and confirming each one plays
- Lower the barrier for new testers to contribute real tests immediately
- Never a dead end — because it compiles to the same test-case engine as everything else, a QuickTest can grow into a full navigation-based test later if needed

---
