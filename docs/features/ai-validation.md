# AI-Powered Validation

Automatic verification using OCR, visual similarity, and device-aware checks.

## What It Covers

- Text presence and OCR confidence checks
- Image/template verification with thresholds
- Screen-state verification after navigation or actions
- Evidence capture for pass/fail triage

## Typical Flow

1. Navigate to target node/state
2. Run verification (`text`, `image`, or combined)
3. Store result and evidence
4. Continue execution or fail fast
