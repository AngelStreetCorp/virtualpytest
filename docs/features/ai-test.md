# 🤖 AI Test Agent

**Describe what to test in plain English. The AI drives the device and tells you if it passed.**

Talk to your lab like a colleague. Instead of writing a script or clicking through a navigation tree, describe what should happen — the AI agent operates the real device, checks the result, and shows you the evidence.

---

## The Problem

Traditional test authoring has a floor of effort under it:
- ❌ Writing (and maintaining) a script takes time and some technical skill
- ❌ Mapping out every screen of an app by hand is tedious before you can even start testing
- ❌ Non-technical stakeholders can't easily ask "does this still work?" without going through a QA engineer

---

## The VirtualPyTest Solution

✅ **Test Prompt** — describe what to do and how to know it passed, in plain language; the AI navigates the real device, performs the actions, and evaluates the result itself, with screenshot evidence
✅ **Automatic app crawling** — point the AI at an app and it explores it on its own, discovering every screen and building the navigation map for you
✅ **Chat-driven control** — ask the AI to inspect, navigate to, or verify something on a live device, and get an answer immediately
✅ **Cross-platform** — works on mobile, Android TV, set-top boxes, and web apps

---

## How It Helps

- Get a test running from a single sentence — no scripting, no manual navigation-tree building
- Map a brand-new app's navigation automatically, instead of doing it screen by screen
- Let anyone on the team — not just engineers — ask real questions about a device's current state
- Turn a one-off question ("does the settings menu still open?") into an answer in seconds
