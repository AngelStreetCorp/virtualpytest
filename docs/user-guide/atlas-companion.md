# Atlas Companion

Atlas answers in the chat first. When the answer comes from data (test results, a run, requirements coverage, incidents, the heatmap), it can also show the real app page, already filtered the same way, in a panel beside the chat.

## Open companion

Under Atlas's answer you see an **Open companion** button with the page name and its filters. Click it and the page opens beside the chat. You can use the page as normal: scroll, open a row, change a filter.

## Follow-ups

Atlas knows which page and filters are shown. A follow-up such as "only failed" changes the filters of the page you are looking at.

## Auto-open

Switch **Auto-open** on in the panel header and Atlas opens pages without asking, so the button no longer appears. Switch it off to be asked again. The choice is remembered in this browser.

## The header toggle

The Companion button in the chat header shows or hides the panel. It is greyed out until Atlas has shown a page. If Atlas updates the page while the panel is hidden, the button pulses and shows a dot; open the panel to clear it.

The panel header also has **Open full page** (the same page in a new tab) and **Hide companion**.
